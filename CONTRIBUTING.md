# Katkıda Bulunma / Contributing

Blueforce RGB Studio açık kaynaklı bir projedir ve katkılara açıktır!

## Nasıl Katkıda Bulunabilirsin?
1. Repoyu fork'la ve kendi branch'ini oluştur (`git checkout -b feature/yeni-ozellik`).
2. Değişikliklerini yap ve `.\build.ps1` ile derlendiğini doğrula.
3. Farklı bir `ZXWMicroChip` (`5566:0008` veya benzeri VID/PID) klavyede test ettiysen model adını `README.md` içindeki uyumlu modeller tablosuna ekleyebilirsin.
4. Pull Request (PR) aç!
